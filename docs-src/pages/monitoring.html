Every service with a web address is checked every few minutes, and you can add sites hosted anywhere else. Lanternly records whether each one is up, how fast it answers, its version and when its certificate runs out, and emails you when something changes.

What's checked

Each check asks <site>/api/health if the site has one, else its home page (or the health page you set). For each site the Monitoring page shows:

  • Status: Up, Down, or Retrying (one check failed; a site only counts as down after two failures in a row).
  • Speed: how long it took to answer.
  • Up, 7 days: the share of checks that passed in the last week.
  • Version: if the health page reports one ({"version": "1.4.0"}).
  • Certificate: days until the HTTPS certificate runs out.

Sites that are down are listed first, and the page refreshes by itself. Paused services and services still being created aren't checked.

Watch a site hosted elsewhere

  1. Under Watch a site hosted elsewhere, type its address, such as https://www.example.org.
  2. Optionally give it a name.
  3. Press Add and check. The first check runs straight away.

Nothing needs installing on that site. Lanternly only watches it; it can't restart or change a site it doesn't run. Private and loopback addresses are refused, so monitoring can't be used to probe your own network.

User numbers from outside sites

A site can also report how many users it has. If it exposes /api/health/stats behind a key, open it on the Monitoring page, scroll to Settings, set the same value as the site's STATS_API_KEY under Key for user numbers and press Save. Lanternly reads the numbers once an hour, only counts, never names or emails.

Labels and groups

Labels sort sites into groups, such as Production and Staging, or one label per client.

  1. Press Edit at the end of a site's row.
  2. Under Labels, pick a label or type a new one and press Enter. A site can have several.
  3. Press Save.
  • Each label gets its own table with its own up, down and behind counts; sites without one are under No label.
  • Group by labels / One list switches between tables and a single list with tags.
  • Click label tags to show only some groups. The browser address keeps your choice, so you can bookmark it.
  • Labels in the toolbar renames, recolours, orders and deletes labels.

A site's history

Click a site for uptime over 24 hours and 7 days, its usual speed and the latest checks (kept 14 days). From there you can rename it, change its address or labels, pause checks and alerts during planned work, or stop watching it.

Alerts

An email goes out when:

  • a site is down (two failed checks in a row),
  • it's back up, with how long it was down,
  • a certificate has 14 days left, and again at 3 days.

Under Alerts, type who should get them (comma-separated). Empty means every owner. Save and send a test email checks delivery. You can also set how often sites are checked (1 to 60 minutes).

The same addresses get database quota, backup and (with the AWS plugin) cost alerts. All of them need the outgoing email account under Settings.
