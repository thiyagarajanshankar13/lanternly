Most configuration lives in the console's Settings. A few values are environment variables, set in /opt/deployer/.env on the deployer VM (or .env.local when running locally).

Console

VariableMeaning
DEPLOYER_SECRET_KEYRequired. 32 random bytes as hex (openssl rand -hex 32). Encrypts the secrets the console stores. Losing it loses them. Made by the setup script.
DEPLOYER_URLThe console's own address, such as https://admin.example.com. Used in links, the authenticator label and the GitHub webhook. Must be public https:// for Connect GitHub and Create server.
DEPLOYER_SETUP_TOKENOne-time code for creating the first owner at /admin/setup. Remove it once the owner exists.
DEPLOYER_DATA_DIRWhere the SQLite database and uploads live. /data in the container (/opt/deployer/data on the VM).
DEPLOYER_DB_FILEDatabase file, if not <data dir>/deployer.sqlite.
DEPLOYER_SSH_KEY_FILE or DEPLOYER_SSH_KEYThe private key the console uses to reach servers: a file path, or the key itself.
DEPLOYER_FAKE_ENGINE1 = practice mode: servers, GitHub, buckets and AWS are simulated. Never on a real install.
DEPLOYER_FAKE_ENGINE_DELAYMilliseconds each simulated step takes, to see progress screens.

Timers

Each background timer can be stopped with off, for example on a second copy of the console used for testing.

VariableStops
DEPLOYER_MONITOR=offMonitoring checks and alerts
DEPLOYER_BACKUPS=offScheduled backups and clean-up
DEPLOYER_DB_WATCH=offDatabase size and quota checks
DEPLOYER_COSTS=offAWS plugin: the daily cost fetch
DEPLOYER_PROVISION=offAWS plugin: server create/delete steps and the daily Lightsail check

Other

VariableMeaning
DEPLOYER_MONITOR_ALLOW_PRIVATELets monitoring check private and loopback addresses. For local testing only.
DEPLOYER_AGENT_DIRAWS plugin: where the agent/ files are that new servers get. Default ./agent in the image.

Deployer VM setup

For deploy/setup-deployer-vm.sh:

VariableMeaning
DEPLOYER_DOMAINRequired. The console's domain, such as admin.example.com.
DEPLOYER_SETUP_TOKENOptional. Your own first sign-in code (16+ characters, no spaces or quotes). Otherwise one is made up and printed.

When starting the console with Docker Compose in /opt/deployer, DEPLOYER_IMAGE names the image to run.

Services VM setup

For agent/setup-clubs-vm.sh:

VariableMeaning
DEPLOYER_PUBLIC_KEYRequired. The console's SSH public key.
ACME_EMAILRequired. Email for Let's Encrypt notices.
AGENT_ROOTFolder for everything on the server. Default /opt/avrosphere.
AGENT_NAMESPACEPrefix of container names, labels and shared networks. Default avrosphere.
GHCR_USER, GHCR_TOKENOptional login for pulling private images from ghcr.io.
