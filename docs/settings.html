Configure

Settings and branding

Settings holds the defaults for every service. Only owners can open it.

#Addresses

  • Domain services live under: the domain your wildcard DNS points at, such as example.com. A service named shop gets shop.example.com. Nothing can be created until it's set.
  • Default time zone: used for backup schedules and dates.

#Outgoing email

An SMTP account the console sends through: monitoring, database, backup and cost alerts, invites and tests. Fill in the SMTP server, user name, password (stored encrypted) and sender address. Any provider works (Amazon SES, Postmark, Mailgun, your own mail server). Until it's set, alerts aren't emailed and pages say so.

#Branding and region

  • Name: shown in the side menu, on the sign-in page and in the authenticator app.
  • Line under the name (optional): also ends every page title.
  • Logo address (optional): an image URL. Empty shows the built-in mark.
  • Locale: how dates and numbers are written, such as en-US, en-GB or de-DE.
  • More reserved names: names no service may take, on top of www, admin, api and the like.

#GitHub apps

The GitHub App used to build and deploy apps: Connect GitHub creates one for you, or enter one by hand. Also the default memory limit per app. See Connect GitHub.

#Plugins

Manage plugins lists the installed plugins with what each adds; turn them on or off, and open a plugin's own settings. Turning a plugin off hides what it adds but never stops anything it created. See Plugins.

#People

Who can sign in is on its own page in the side menu. See People and access.
