Get started

Quick start

Run the console on your own computer to look around before you set up any servers. Practice mode simulates the services VM and GitHub, so every screen works.

#What you need

  • Node.js 20 or newer and npm
  • Git
  • OpenSSL (to make two random values)

#Run it

  1. Get the code.

    git clone https://github.com/thiyagarajanshankar13/lanternly.git
cd lanternly
npm install

  2. Make a settings file. Copy the example and fill in three values.

    cp .env.example .env.local
    # .env.local
DEPLOYER_SECRET_KEY=<output of: openssl rand -hex 32>
DEPLOYER_SETUP_TOKEN=<output of: openssl rand -hex 16>
DEPLOYER_FAKE_ENGINE=1

  3. Start it.

    npm run dev

    Open http://localhost:3100/admin.

  4. Create the first owner. Enter the setup code (your DEPLOYER_SETUP_TOKEN), your name, email and a password, then scan the QR code with an authenticator app (1Password, Google Authenticator, Authy…) and type the 6-digit code.

  5. Look around. Practice mode comes with a pretend server and three pretend GitHub repos. Try:

    • Projects → New project, then New service → PostgreSQL database.
    • New service → App from GitHub, pick a repo and tick the database. Builds finish at once.
    • New service → Docker image with nginx:1.27.
    • Monitoring, Backups and People.
Practice mode is only for trying things

With DEPLOYER_FAKE_ENGINE=1 nothing is really created and the AWS plugin's Costs page shows made-up numbers. Leave it unset on a real install.

#Try clubctl for real

To see the server side work on a machine with Docker (a spare VM or a Linux laptop), run the services setup locally and use names under .localhost:

sudo ./agent/setup-clubs-vm.sh
